# Glossaire — myBudget

| Terme                  | Définition                                                                                                                                                                                                                                                                                     | Synonymes / usage                                                                                                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Compte**             | Un compte bancaire de l'utilisateur. Un utilisateur peut posséder **plusieurs comptes**, chacun géré de façon totalement **indépendante et distincte** dans l'application — jamais de somme consolidée entre comptes.                                                                          | Ne pas confondre avec "compte utilisateur" (il n'y a qu'un seul utilisateur/profil dans l'app) — ici "compte" désigne toujours un compte bancaire.                       |
| **Budget mensuel**     | Le cycle budgétaire de référence de l'application, aligné sur le **mois calendaire** (pas de cycle personnalisé, ex. pas d'alignement sur une date de salaire), calculé **par compte**.                                                                                                        | Ne pas confondre avec "budget" au sens générique (enveloppe globale) — ici c'est toujours une période d'un mois calendaire, propre à un compte.                          |
| **Dépense**            | Sortie d'argent rattachée à un compte, catégorisée via un **type de dépense** de niveau 3 (voir ci-dessous).                                                                                                                                                                                   | —                                                                                                                                                                        |
| **Type de dépense**    | Élément du référentiel hiérarchique à 3 niveaux **propre à chaque compte** : Niveau 1 (`fixe`/`variable`, dérivé à la création d'un niveau 2), Niveau 2 (catégorie, ex. "Maison"), Niveau 3 (ligne concrète portant le montant, ex. "Crédit immobilier").                                      | —                                                                                                                                                                        |
| **Montant historisé**  | Mécanisme de stockage du montant d'un type de dépense (niveau 3) : une nouvelle valeur n'est enregistrée que lors d'un changement (évolution, disparition, réapparition) — le montant d'un mois donné se résout par la dernière valeur connue à cette date, sans dupliquer les mois inchangés. | Aussi appelé "historisation par changement" / pattern proche d'un SCD (Slowly Changing Dimension).                                                                       |
| **Montant disponible** | Le montant restant chaque mois, **pour un compte donné**, une fois les dépenses de ce compte couvertes par rapport à ses revenus — c'est la capacité de l'utilisateur à dépenser ou investir librement sur le mois, compte par compte.                                                         | Aussi appelé familièrement "argent de poche" dans les échanges produit, mais **le terme fonctionnel officiel à utiliser dans le code et l'UI est "montant disponible"**. |
| **Revenu**             | Entrée d'argent rattachée à un compte, sur le mois (ex : salaire). Base du calcul du montant disponible de ce compte.                                                                                                                                                                          | —                                                                                                                                                                        |

> Ce glossaire sera enrichi au fil des tickets, notamment lors de la définition détaillée du modèle de dépenses (niveaux 1/2) et des règles de calcul.
